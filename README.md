# mern-expense-tracker

## Problem Statement
College students and young adults often struggle to keep track of daily pocket expenses and pocket allowances, making it difficult to understand where their money goes without a quick digital logger.

## Target Users
* **Registered User:** Can securely sign up, log in, and manage their own income/expense records without seeing other users' data.

## MVP Scope (Must Haves)
* User authentication (Register/Login with JWT and hashed passwords).
* Full CRUD operations for financial transactions (Title, Amount, Category, Type: Income/Expense, Date).
* Summary metrics showing total income, total expenses, and net balance.
* Responsive mobile-first design.

## Tech Stack
* **Frontend:** React (Vite), React Router, Lucide Icons / CSS
* **Backend:** Node.js, Express.js, Mongoose, bcryptjs, jsonwebtoken
* **Database:** MongoDB Atlas
